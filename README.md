1. Información general

Esta Política de Privacidad describe el tratamiento de información relacionado con [NOMBRE DEL JUEGO], un videojuego educativo desarrollado por [NOMBRE DEL DESARROLLADOR O EMPRESA].

La aplicación permite aprender y practicar conceptos de programación mediante realidad aumentada (AR), así como importar y exportar niveles diseñados por los usuarios en formato JSON.

La aplicación está diseñada para funcionar sin que el desarrollador recopile deliberadamente datos personales, cree perfiles de usuarios o registre métricas propias de uso. Sin embargo, algunos servicios técnicos de terceros necesarios para determinadas funciones, como Google Play Services for AR (ARCore), pueden tratar datos técnicos conforme a sus propias políticas.

2. Datos personales y métricas

El desarrollador no solicita deliberadamente nombres, direcciones de correo electrónico, números de teléfono, contactos, ubicación, fotografías personales ni otros datos de identificación para utilizar las funciones principales del videojuego.

La aplicación no incorpora intencionadamente sistemas propios de analítica, seguimiento publicitario o elaboración de perfiles de comportamiento.

Esta declaración se refiere a las funciones y dependencias efectivamente incluidas en la versión publicada. El uso de servicios de terceros puede implicar tratamientos técnicos adicionales, descritos en esta política.

3. Cámara y realidad aumentada

La aplicación solicita permiso para utilizar la cámara cuando el usuario activa las funciones de realidad aumentada. La cámara permite a ARCore interpretar el entorno físico y colocar elementos virtuales dentro de la experiencia de juego.

El desarrollador no utiliza deliberadamente la cámara para identificar personas, realizar reconocimiento de identidad, grabar conversaciones o recopilar fotografías con fines publicitarios o de seguimiento.

En la funcionalidad AR local descrita por esta aplicación, las imágenes del entorno se utilizan para proporcionar la experiencia de realidad aumentada. No obstante, el tratamiento de datos por parte de ARCore depende de las API utilizadas.

Si se habilitan funciones que transmiten datos a los servicios de Google, dicho tratamiento se regirá también por la información y las políticas de Google.

El usuario puede denegar o revocar el permiso de cámara desde los ajustes del dispositivo. Sin este permiso, las funciones que dependan de la realidad aumentada no estarán disponibles.

4. Google Play Services for AR (ARCore)

Esta aplicación utiliza Google Play Services for AR (ARCore), proporcionado por Google. Este servicio permite que el videojuego interprete el entorno y presente contenido de realidad aumentada.

De acuerdo con la documentación de Google, ARCore puede recopilar identificadores de usuario o dispositivo, datos de rendimiento y diagnóstico, y datos sobre el uso de sus API para mantener, analizar y mejorar el servicio.

El tipo de información tratada depende de las funciones de ARCore utilizadas. Algunas funciones avanzadas, como Cloud Anchors o la API Geospatial, pueden implicar tratamiento adicional de datos de cámara o ubicación.

Para más información, consulta:

Política de Privacidad de Google
Requisitos de privacidad de ARCore
Cómo Google Play Services for AR trata los datos

El desarrollador no controla de forma independiente todos los tratamientos que Google realiza mediante ARCore. Para conocer sus prácticas, los usuarios deben consultar la documentación y las políticas del proveedor.

5. Importación y exportación de archivos JSON

La aplicación permite importar archivos JSON para cargar niveles y exportarlos para guardar niveles creados o modificados por el usuario.

Estos archivos pueden contener la estructura, configuración, objetos y propiedades que formen parte del formato de los niveles del videojuego.

5.1. Importación de archivos

Para importar un nivel, el usuario selecciona el archivo mediante el selector de documentos de Android. La aplicación procesa el contenido seleccionado con el propósito de cargar el nivel correspondiente.

La aplicación no utiliza esta función para buscar indiscriminadamente otros archivos del dispositivo.

5.2. Exportación de archivos

Para exportar un nivel, la aplicación genera un archivo JSON y permite al usuario elegir el nombre y la ubicación de destino mediante las opciones disponibles en el sistema operativo.

Los archivos exportados quedan bajo el control del usuario, que puede conservarlos, modificarlos, compartirlos o eliminarlos.

5.3. Almacenamiento y transmisión

Los archivos se procesan localmente en el dispositivo. El desarrollador no recibe copias de estos archivos a través de un servidor propio.

Si el usuario decide compartir un archivo mediante otra aplicación o servicio externo, el tratamiento posterior estará sujeto a las políticas y condiciones del servicio elegido.

El usuario debe revisar los archivos antes de compartirlos, especialmente si el formato permite incluir información escrita libremente.

6. Almacenamiento y conservación

La aplicación puede almacenar localmente los datos necesarios para su funcionamiento y los niveles que el usuario decida guardar.

No mantiene deliberadamente una base de datos remota de cuentas de usuario o niveles.

Los datos guardados en el almacenamiento privado de la aplicación pueden eliminarse al borrar sus datos o desinstalarla, según el comportamiento de Android y la implementación del videojuego.

Los archivos exportados a otras ubicaciones pueden permanecer en el dispositivo después de la desinstalación y deberán eliminarse por separado.

El desarrollador no conserva copias remotas de los niveles importados o exportados mediante la funcionalidad local descrita en esta política.

7. Compartición de información con terceros

El desarrollador no vende ni comparte deliberadamente datos personales de los usuarios con fines publicitarios, comerciales o de elaboración de perfiles.

Google Play Services for AR puede tratar los datos técnicos descritos en la sección 4.

Otros componentes de terceros que pudieran incluirse en futuras versiones se evaluarán para determinar sus prácticas de tratamiento de datos.

Si se incorporan servicios que cambien de manera sustancial las prácticas de privacidad de la aplicación, esta política se actualizará para describir dichos cambios.

8. Publicidad y analítica

La aplicación no incorpora intencionadamente publicidad personalizada ni sistemas propios de seguimiento publicitario o analítica de comportamiento.

El tratamiento técnico que realice ARCore se describe en la sección 4 y no debe confundirse con las métricas propias del videojuego.

9. Seguridad

El procesamiento local de los niveles reduce la necesidad de transmitir archivos a servidores del desarrollador.

El acceso a documentos se limita a los archivos seleccionados por el usuario mediante los mecanismos de Android.

Ningún sistema digital puede garantizar seguridad absoluta. Se recomienda importar archivos de fuentes confiables y revisar su contenido antes de compartirlos.

El desarrollador no controla las prácticas de seguridad de aplicaciones o servicios externos a los que se envíen archivos.

10. Control del usuario y eliminación de datos

El usuario puede gestionar los permisos concedidos a la aplicación, seleccionar los archivos que desea importar, elegir dónde guardar los archivos exportados y eliminar los datos locales mediante las opciones disponibles en su dispositivo.

Como la aplicación no requiere una cuenta ni mantiene deliberadamente un perfil remoto del usuario, no existe un procedimiento de eliminación de cuenta dentro del videojuego.

Los tratamientos efectuados por proveedores externos, incluido Google, se rigen por las políticas y opciones de privacidad de dichos proveedores.

Las consultas relacionadas con los datos tratados por el desarrollador pueden dirigirse al contacto indicado al final de esta política.

11. Público y privacidad de menores

La aplicación está dirigida al público general y tiene una finalidad educativa.

No solicita deliberadamente información personal para identificar a sus usuarios ni utiliza datos personales para crear perfiles publicitarios.

Esta declaración no significa que la aplicación esté específicamente diseñada para niños ni sustituye las obligaciones que puedan resultar aplicables a las aplicaciones dirigidas a menores.

La clasificación del público objetivo y el cumplimiento de las políticas de Google Play deberán reflejar el diseño y la promoción reales del videojuego.

12. Permisos del dispositivo

El permiso de cámara se utiliza para la realidad aumentada.

La importación y exportación de archivos se realiza mediante el selector de documentos de Android, que permite al usuario elegir los archivos y ubicaciones correspondientes.

La aplicación no necesita acceso general a todos los archivos del dispositivo para la funcionalidad de importación y exportación descrita en esta política, siempre que la implementación utilice exclusivamente el selector de documentos y no solicite permisos adicionales de almacenamiento.

13. Cambios en esta política

Esta política podrá actualizarse si cambian las funciones de la aplicación, las tecnologías utilizadas o los requisitos legales o de las plataformas de distribución.

La versión vigente estará disponible en la página pública donde se publique esta política. La fecha de actualización se modificará cuando corresponda.

Si se introducen cambios sustanciales en el tratamiento de datos personales, se proporcionará información adicional o se solicitará el consentimiento correspondiente cuando resulte necesario.
